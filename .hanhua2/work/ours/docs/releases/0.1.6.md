# DroidDeck 0.1.6（预发布）

**SteamDeck 现在是 DroidDeck。全新安装现在会在首次登录时自行设置：加载屏幕上的 Linux 运行时，然后在你登录后直接提供 Proton Experimental (ARM64)，一旦到位客户端会自行重启。另有带下载的整页驱动选择、全程控制器导航、会话暂停模式、Deck 模式、第二屏模式和 Android 主屏幕应用集成。**

> ⚠️ **一个新应用，不是更新。** DroidDeck 有一个新的应用 ID（`com.droiddeck.launcher`），因此它**安装在 SteamDeck 0.1.5 旁边**而不是覆盖它：Linux 运行时重新下载，你再次登录 Steam，设置重新开始。日志现在位于 `Download/DroidDeck/`，开关文件是 `droiddeck-env`、`droiddeck-osc` 等等——旧的 `steamdeck-*` 名称不再被读取。用完 SteamDeck 后请将其移除。

---

## 名称

应用、其 ID、其代码及其写入的一切都是 **DroidDeck**；仓库是 `The412Banner/DroidDeck`。Valve 自己的 *Steam Deck* 名称保持原样（客户端的 `-steamdeck` 标志、`steamdeck_publicbeta` 分支、“Steam Deck 模式”）。 在 AYN Pocket FIT 上安装并登录：日志、会话报告和包都显示 DroidDeck。

## 首次运行自行设置

- **Play 和 Desktop 在全新安装上工作。** 加载屏幕下载、检查并解包 Linux 运行时（然后对于 Desktop 是桌面包）并启动会话；失败会在加载屏幕上以原因结束。
- **首次登录后立即 Proton Experimental (ARM64)。** 未登录的客户端过去会丢弃安装请求，因此对话框只在手动重启后出现。会话现在监视登录，再次询问，并且一旦 depot 到位就自行重启客户端一次，因此在安装游戏之前兼容性工具列表和默认值都是最新的（从 Bannerlator 移植）。 在 FIT 上全新安装：登录 → 对话框 → 安装 474 MB → 客户端在几秒内自行重启。
- 加载屏幕不再声称 Steam 在后台保持运行（见下文）。

## 驱动，作为整页

**Steam 会话 › 运行时驱动 / 显示驱动** 打开整页而不是下拉菜单：已安装驱动（点击使用，标记为捆绑/已下载/已导入）、来自 **Banners-Turnip** 和 **WinNative** 最新发布的**下载**（Android 和 Linux 构建，每个变体来自携带它的最新发布）、一个**刷新**按钮，这是唯一联网的东西，以及**每个驱动上的垃圾桶**——包括捆绑的，带 *恢复内置驱动*。删除正在使用的驱动会回退到自动/运行时默认。 下载、选择和删除已在 FIT 上使用。

## 控制器导航

每个设置控件都显示焦点轮廓；驱动页面打开时聚焦正在使用的驱动，上到达刷新，右到达驱动的垃圾桶，Back 返回一级到你离开的地方。会话设置打开时其第一个控件获得焦点。**会话内抽屉**现在在其 STEAM 按钮上打开，并在打开时接管控制器（d-pad 和摇杆移动，A 选择，B 关闭），而不是游戏接收它。Play 和 *credits* 也有轮廓。 在 FIT 上。

## 后台会话（Kurt）

**后台行为：自动 / 手动 / 从不。** 自动在应用离开屏幕时暂停会话，并在你回来时恢复；手动暂停并等待恢复；从不保持运行。音频在暂停后恢复。Android 杀死的会话不再让下一次启动停留在更新旋转器或空白 Gamepad UI 上（其残留物在启动时清除）。 清理已在 FIT 上。

## Steam Deck 模式

`-steamdeck` 带 SteamOS 助手 stub（无重启循环、无“Update Error”、无 dock-firmware 行），默认 `steamdeck_publicbeta` 通道，Quick Access Menu 中的电池，QAM 缩放过滤器中的 **NIS**，以及 QAM 的**性能覆盖**由 mangoapp (MangoHud) 绘制，捆绑在应用中。 QAM 和电池已在 FIT 上；⚠️ NIS 和覆盖尚未尝试。

## 更多

- **你自己的游戏**来自任意数量的文件夹，在客户端库中作为非 Steam 游戏出现在 ARM64 Proton 下，商店封面按名称查找。
- **音频：** 客户端默认回到 0.1.5 的经典 sink（DirectAudio 是一个选择）；游戏保持 DirectAudio；麦克风开启。*Setup › Session logs › Share latest logs.*
- **显示：** 用于 4:3 和 3:2 掌机的 *Exactly this panel* 形状，以及按模式的自定义分辨率。
- **第二屏（Kurt）：** 键盘 + 触控板控件，或副显示器上的 Linux 终端。
- **Android 主屏幕应用（Kurt）：** DroidDeck 可以被选为 Home 应用；Home 返回到正在运行的会话，已安装的 Android 应用可以从前端和抽屉启动。
- **Steam 和 QAM 触摸按钮（Kurt）** 用于屏幕控件，以及抽屉标题中。
- **启动器面板（Kurt）：** Steam、Desktop 和 Setup 是一致的标签页；桌面应用从它们自己的页面安装和卸载；兼容性工具就地管理。
- 应用自己的 gamescope 构建（ARM64 客户端修复、实时队列、手柄光标）和它自己的音频 sink 随 APK 一起发布；托管的运行时未变。

## 延续——仍然未决

- 在某些 Android 16 手机上，Firefox 的标签页崩溃（共享内存 seals；`Download/droiddeck-env` 中的 `MOZ_SHM_NO_SEALS=1` 是正在尝试的解决方法），并且 RPCS3 AppImage 无法解包。
- NIS 和 Deck 模式性能覆盖未测试。受 VAC 保护的游戏报告不安全；仅 Linux 的 Steam 游戏不会启动。
