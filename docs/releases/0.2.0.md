# DroidDeck 0.2.0（beta）

**Valve 的原生 ARM64 Steam 客户端，运行在你的 Android 掌机上。** Windows 游戏通过 Valve 的 ARM64 Proton 和 FEX 运行，可选的 Linux 桌面还带来模拟器。

![在 Android 主屏幕上点击 DroidDeck 并进入 Steam Big Picture](https://raw.githubusercontent.com/Droid-Deck/DroidDeck/main/docs/releases/media/0.2.0/launch-into-steam.gif)

**需要：** Android 9+、Adreno 730 或更新（或 8xx）、约 3 GB 可用空间用于运行时（+1.1 GB 用于桌面与应用）。

这是来自 [Droid-Deck](https://github.com/Droid-Deck) 组织的首个版本，因此它涵盖 DroidDeck 所做的一切，而不仅仅是自 0.1.7 以来更改的内容。`legacy#N` 链接指向 [The412Banner/DroidDeck](https://github.com/The412Banner/DroidDeck) 中的 pull requests，来自迁移之前。

## 亮点

### Steam，原生运行
Big Picture 中的真正 Steam 客户端，从你设备上的 Valve 获取。打开 **Run Steam when DroidDeck starts**，应用图标会直接带你进入，如上所示。

### 为掌机打造的启动器
你的 Steam 库作为胶囊墙，以及一个带每游戏设置的 Games 标签页。

### 你的 Android 主屏幕
将 DroidDeck 设为 Home 应用，你的 Android 应用也生活在启动器中，以及会话菜单中，因此你可以打开一个而不离开游戏。

- 按请求下载的模拟器：RetroArch、PPSSPP、RPCS3、DuckStation、ARMSX2、Dolphin、melonDS、Cemu 等（@The412Banner）
- 模拟器游戏从前端全屏启动，每碟一个 tile，带盒装封面（@The412Banner，[legacy#29](https://github.com/The412Banner/DroidDeck/pull/29)，[legacy#34](https://github.com/The412Banner/DroidDeck/pull/34)，[legacy#38](https://github.com/The412Banner/DroidDeck/pull/38)）
